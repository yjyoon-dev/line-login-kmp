# Artwork

`banner.png` is the README header. It is generated, not hand-drawn, so it can be regenerated at a
different size or with different wording — the script lives in the commit that added it.

It deliberately contains **no LINE artwork**. LINE's guidelines cover the login button, not project
banners, and putting their mark on a banner would read as endorsement — which the README explicitly
disclaims. The green (`#06C755`) is the only borrowed cue; the two overlapping rounded squares stand
for the two platforms, paired with Kotlin's purple (`#7F52FF`).
